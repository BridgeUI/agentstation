# 利用者向け：自分の環境を使い始める（Hanako / Jiro）

Mac mini の中にあなた専用の macOS（VM）があり、そこで Claude Code が動き続けます。スマホや PC の Claude アプリから「Remote Control」でつないで使います。この文書は、最初の 1 回だけやることと、日常の使い方です。

- ダッシュボード：`https://workstation.example.com/`（会社の Google アカウントでログイン）
- あなたの環境：Hanako は `vm1`、Jiro は `vm2`。ダッシュボードでは「Hanako の環境」「Jiro の環境」と出ます
- macOS のユーザー名はメールの @ より前（`hanako` / `jiro`）。ログインパスワードは Taro から受け取ります
- 困ったら Taro に。直し方は `docs/runbook.md`

## 1. 最初の 1 回だけやること（10 分）

### 1-1. 画面を開く

ダッシュボードの自分の環境 › 接続 › **「画面共有（ブラウザ）」**（`vnc-vm1.example.com` / `vnc-vm2.example.com`）を開きます。VNC のパスワードは同じページの「VNC アプリ」の行の **「パスワードを表示」** で 60 秒だけ出ます。

- ブラウザ版はマウスカーソルが描画されないことがあります。クリックは効くので、ボタンの上で止めて色が変わるのを目安にしてください
- macOS のロック画面が出たら、自分のユーザー名とログインパスワード

### 1-2. 残っている設定画面を閉じる

初回は「Update Mac Automatically」という画面が出ています。**「Only Download Automatically」→「Continue」** で閉じます。Apple ID などを聞かれても全部スキップで構いません。

### 1-3. Claude にログインする

デスクトップでターミナル（Launchpad › その他 › ターミナル）を開き、順に実行します。

```bash
claude auth login
```

ブラウザが開くので、**自分の Claude アカウント**（Hanako はアカウント B、Jiro はアカウント C）でログインします。手で起動するものはありません。作業フォルダ（`~/workspace`）の信頼と Remote Control の初回の許可は、Mac 側の仕組み（エージェント）が代わりに記録します。

### 1-4. 確認

ログインが済むと Remote Control が自動で起動し、1〜2 分後、ダッシュボードの自分の環境で **Remote Control が「接続中」** になります。スマホや PC の Claude アプリに `vm1-…` / `vm2-…` という名前のセッションが見えれば完了です。

## 2. 日常の使い方

- **Claude アプリから**：Remote Control の一覧から自分の環境を選んで会話します。作業フォルダは `~/workspace` で、その下のプロジェクトを読み書きできます
- **プロジェクトごとに分けたいとき**：ダッシュボード › **Remote Control タブ**（自分の環境を開くと最初に出る）。`~/workspace` 直下のフォルダを選んで「起動」すると、そのフォルダ名の Remote Control がもう 1 つ立ち上がります。「新しいフォルダ」から作成もできます（「作成後に Remote Control を起動」にチェック）
- **権限の確認**：Remote Control は既定で「権限の確認を省く」（bypassPermissions）。書き込みやコマンド実行のたびに Claude アプリで許可を求めてほしい人は、ダッシュボード › 操作 › 「権限の確認を省く」をオフにする（RC が立て直される）
- **止まった・つながらないとき**：ダッシュボード › 操作 › **「Remote Control を立て直す」**。数分前の会話に戻したいときは **「前のセッションを戻す」**（約 4 時間以内）
- **ターミナルで入りたいとき**：ダッシュボード › 接続 › **「SSH（ブラウザ）」**。パスワードは要りません（Cloudflare の短期証明書）
- **スマホから入りたいとき**：Cloudflare One（WARP）アプリをオンにして、SSH は WebSSH、画面共有は DualMac（Termius は Cloudflare の SSH 中継と相性が悪くつながらない）。接続先は `192.168.64.10`（Hanako）/ `.11`（Jiro）、ユーザー名は自分の名前、画面共有のパスワードはダッシュボードの「パスワードを表示」。手順はガイドの「入り方」。Wi‑Fi につないでいるときは、アプリ初回の「ローカルネットワーク上のデバイスの検索と接続を許可」を許可する（許可しないと無言でタイムアウトする。モバイル回線では不要）
- **スマホの「ファイル」アプリで作業フォルダを見たいとき**：**WARP をオンにしてから**（オフだと無言でタイムアウトする）、ファイル › … › サーバへ接続 › `smb://192.168.64.10`（Jiro は `.11`）› 登録ユーザ（名前は自分のユーザー名、パスワードは Mac のログインパスワード）› `workspace`。アドレスはダッシュボード › 接続 の「ファイルアプリ」の行にも出ます。手順はガイドの「入り方」
- **PC から入りたいとき**：WARP をオンにして、Mac の「画面共有」アプリで `vnc://192.168.64.10`、ターミナルで `ssh hanako@192.168.64.10`（Jiro は `.11` と `jiro`）
- **ログイン切れ**：ダッシュボードに「要ログイン」と出たら、1-1 → 1-3 をもう一度（`claude auth login`）。Remote Control は自動で戻ります。Slack にも通知が来ます

## 2.5 Codex（ChatGPT）も使うとき

自分の Mac に ChatGPT アプリを入れて（Taro に頼む）、自分の ChatGPT アカウントでログインし、アプリの設定で Remote Control を有効にします。スマホの ChatGPT アプリから接続できます。ダッシュボードでは「Codex」の状態が出て、止まったときは「Codex を再起動」でアプリを開き直せます。

## 3. やらないでほしいこと

- **ログアウトしない**（画面共有を閉じるだけにする）。ログアウトすると Remote Control が止まります
- **スリープや省電力、ソフトウェアアップデートの設定を変えない**。Taro が管理しています
- **Claude Code の自動更新をオンにしない**（`~/.claude/settings.json` の `DISABLE_AUTOUPDATER`）。更新はダッシュボードの「Claude Code を更新」から
- **macOS を自分で再起動・シャットダウンしない**。必要なときはダッシュボードの操作か Taro に
- **ログインパスワードを変えたら Taro に伝える**。自動ログインの設定を直さないと、再起動後にログイン画面で止まります
- 会話の内容やファイル名はダッシュボードには送られません。送られるのは状態（動いている・止まっている）と、作業フォルダ直下のフォルダ名、セッションの名前だけです

## 4. 自分の環境のスペック

- CPU 4 コア（Mac mini の 12 コアを共有）、メモリ 6GB、ディスク 90GB
- 毎晩 04:00 ごろに自動で更新と再起動が入ります（作業中なら見送ります）
- 画面の解像度は 1024×768（画面共有での操作は最初の 1 回だけなので、そのままにしています）
