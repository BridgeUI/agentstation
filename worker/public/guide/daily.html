普段の使い方

はじめての設定が済んでいれば、普段はスマホや PC の Claude アプリから使います。 ダッシュボードでは、動いているかを確かめ、止まったときに直すボタンを押します。

Claude アプリからつなぐ

  1. Remote Control
    vm1-breezy-lynx接続中
    my-projectフォルダごとの Remote Control
    1
    Claude アプリ › Remote Control › 自分の環境を選びます 名前は vm1-…（Jiro さんは vm2-…）です。あとは普通に会話します。Claude は自分の Mac の中のファイルを読み書きしながら作業します。作業フォルダは ~/workspace で、その下のプロジェクトがすべて対象です。

Remote Control を遠隔で起動・停止する

Remote Control の起動と停止は、スマホや PC のダッシュボードからできます。自分の Mac の画面を開く必要はありません。 ボタンを押してから実際に動くまで最大 1 分かかります。Mac 側が 1 分ごとに指示を取りに来る仕組みのためです。

  1. Remote Control を立て直す
    止めて、同じ作業フォルダで起動し直します。
    キャンセル立て直す
    1
    メインの Remote Control は「操作」タブ › 「Remote Control を立て直す」で起動します 普段は自動で動き続けています。止まったときや返事が無いときに押します。1 分ほどで Claude アプリに vm1-… が戻ります。
  2. フォルダごとの Remote Control
    my-project　未起動
    起動
    2
    プロジェクトごとの Remote Control は、フォルダを選んで「起動」します 「Remote Control」タブ（開いたときに最初に出るタブ）にあります。~/workspace 直下のフォルダの行で「起動」を押すと、そのフォルダだけを対象にした Remote Control がもう 1 つ立ち上がり、Claude アプリにフォルダ名で出ます。使い終わったら「停止」を押します。
  3. Remote Control
    vm1-breezy-lynxメイン · ~/workspace 全体
    my-projectフォルダごと · ~/workspace/my-project
    3
    Claude アプリで確かめます メインとフォルダごとの Remote Control が並んで表示され、どちらからでも会話できます。Remote Control の許可は Mac 側が記録済みなので、遠隔起動のたびに許可を求められることはありません。

ダッシュボードの見方

  1. 1
    一覧には 3 人分の状態が出ます 「正常」なら何もしなくて済みます。「要確認」のときは上に理由が出ます。右の CPU・メモリ・ディスクは、Mac 全体のうち自分が使っている割合です。開いている間は 5 秒ごとに自動で更新します。
  2. 2
    自分の環境のページには 6 つのタブがあります 概要（Claude と Remote Control の状態）、Remote Control（フォルダごとの起動・停止。開いたときに最初に出ます）、接続（画面共有・SSH・ファイルアプリの入り口）、操作（直すボタン）、基礎設定（Taro が見る管理項目）、履歴（誰がいつ何を押したか）。普段見るのは Remote Control と操作です。
Claude Code：稼働中 / 停止中 Claude 本体が動いているかどうかです。停止中でも Mac 側の仕組みが自動で起動し直します。
Remote Control：接続中 / 再接続待ち Claude アプリからつなげる状態かどうかです。「再接続待ち」が数分続いたら「立て直す」を押します。
要ログイン Claude のログインが切れています。ログインが切れたときの手順でログインし直します。

操作ボタン（「操作」タブ）

Remote Control を立て直す アプリからつながらないときや、返事が止まったときに押します。1 分ほどで直ります。進行中の会話は切れますが、「前のセッションを戻す」で戻せます。
前のセッションを戻す 立て直しや再起動で切れた会話を、約 4 時間以内なら元に戻します。一覧から会話の名前を選びます。
Claude Code を更新 Claude 本体を最新版にして立て直します。自分で claude update を実行する必要はありません。
VM を再起動 / 停止 / 起動 自分の Mac そのものを再起動します。「立て直す」で直らないときに使います。数分かかります。
Codex を再起動 ChatGPT アプリを使っている人向けです。アプリを終了して開き直します。
権限の確認を省く（オン / オフ） オンのとき、Claude アプリでファイルの書き込みやコマンド実行のたびに許可を求めません。この Mac は Claude 専用なので既定はオンです。毎回確認したい人はオフにします。切り替えると Remote Control を立て直します。
Claude Code の既定で権限の確認を省く（オン / オフ） ターミナルで claude を起動したときの既定です。上の Remote Control 用とは別の設定で、切り替えても Remote Control は切れません。
どのボタンも、押すと「履歴」タブに受付・実行中・完了の順で残ります。押してから実際に動くまで最大 1 分かかります。

プロジェクトごとの Remote Control

メインの Remote Control は ~/workspace 全体が対象です。特定のプロジェクトだけを対象にした Remote Control をもう 1 つ立ち上げることもできます。Claude アプリにはフォルダ名で表示されます。

候補になるのは、そのマシンの作業フォルダ ~/workspace の中（直下）にあるフォルダだけです。ほかの場所にあるフォルダは一覧に出ません。プロジェクトは ~/workspace の中に置いてください（git clone もそこで行います）。

  1. フォルダごとの Remote Control
    my-project　未起動
    起動
    1
    「Remote Control」タブで、フォルダの行の「起動」を押します 一覧は ~/workspace の直下にあるフォルダです（サブフォルダは出ません）。数秒〜1 分ほどで「稼働中」になり、Claude アプリに my-project のような名前で出ます。止めるときは「停止」を押します。
  2. 新しいフォルダ
    my-project
    作成後に Remote Control を起動
    作成
    2
    「新しいフォルダ」で作って、そのまま起動できます 名前は英数字で始め、英数字・空白・. _ - だけで 64 文字までです。「作成後に Remote Control を起動」にチェックを入れると、作成と起動が一度に済みます。フォルダは ~/workspace の中に作られます。
  3. Remote Control を起動
    「my-project」を信頼済みフォルダとして記録し、起動します
    起動やめる
    3
    起動＝そのフォルダを信頼する、です Claude Code はフォルダ単位で信頼を求めます（git リポジトリは特に）。「起動」を押すと、そのフォルダを信頼済みとして記録してから立ち上げるので、別の手順はありません。信頼すると、そのフォルダの CLAUDE.md・フック・設定が読み込まれます。中身を知っているフォルダだけ起動してください。

スマホのホーム画面に追加する

iPhone（Safari） ダッシュボードを開き、共有ボタン › 「ホーム画面に追加」を選びます。アプリのように全画面で開き、下にタブが出ます。
Android（Chrome） メニュー（⋮）› 「ホーム画面に追加」または「アプリをインストール」を選びます。
ログインの期限 Cloudflare のログインは 24 時間で切れます。切れたら Google でログインし直します。

やらないでほしいこと

ログアウトしない 画面共有は閉じるだけにしてください。macOS からログアウトすると Remote Control が止まり、Taro の作業が必要になります。
再起動・シャットダウンしない 必要なときはダッシュボードの「VM を再起動」を使ってください。
設定を変えない スリープ・省電力・ソフトウェアアップデートの設定と、Claude Code の自動更新は Taro が管理しています。
パスワードを変えたら伝える Mac のログインパスワードを変えたら Taro に伝えてください。自動ログインの設定を直さないと、次の再起動でログイン画面のまま止まります。
会話の内容やファイル名はダッシュボードに送りません。送るのは状態（動いている・止まっている）、作業フォルダ直下のフォルダ名、セッションの名前です。
