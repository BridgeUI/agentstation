使い方ガイド

自分の Mac で Claude を使う

会社の Mac の中に、あなた専用の Mac（仮想マシン）があります。そこで Claude Code が動き続けていて、 スマホや PC の Claude アプリから Remote Control でつないで使います。このガイドは 4 つに分かれています。

最初の 1 回だけ · 約 10 分 はじめての設定 ダッシュボードへのログイン、自分の Mac の画面を出す、Claude へのログイン。Remote Control はログインが済めば自動で起動します。初日はここから始めます。 毎日 普段の使い方 Claude アプリからつなぐ、ダッシュボードの見方、Remote Control の遠隔起動、プロジェクトごとの Remote Control。 必要なとき 入り方（画面共有・SSH・ファイル） 自分の Mac の画面を見る方法、文字だけで入る方法、スマホの「ファイル」アプリで作業フォルダを開く方法。ブラウザで入る方法と、WARP をオンにしてアプリで入る方法。 うまくいかないとき 困ったとき 「要ログイン」と出た、つながらない、パスワードが通らない。やらないでほしいことも書いています。

あなたのユーザー名と、2 つのパスワード

Mac のユーザー名 Hanako さん → hanako Jiro さん → jiro メールアドレスの @ より前と同じです。SSH のユーザー名もこれです。
① Mac のログインパスワード Taro から受け取ります ロック画面（名前の下にパスワード欄がある画面）で使います。変えたときは Taro に伝えてください。
② 画面共有（VNC）のパスワード ダッシュボードで表示します 8 文字です。自分の環境 › 「接続」タブ › 「パスワードを表示」を押すと 60 秒だけ出ます。①とは別のパスワードです。

しくみ

自分の Mac はどれか Hanako さんは「vm1」、Jiro さんは「vm2」です。ダッシュボードでは「Hanako の環境」「Jiro の環境」と表示します。
普段の使い方 スマホや PC の Claude アプリから Remote Control でつなぎます。このガイドの手順が必要なのは、最初の 1 回と、調子が悪いときです。
Google のパスワード ダッシュボードと Cloudflare へのログインに使います。いつもの会社アカウントです。
