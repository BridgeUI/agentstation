使い方ガイド · うまくいかないとき

困ったとき

まずダッシュボードの一覧を見てください。「応答なし」なら Mac 側の問題なので、Taro に連絡します。それ以外はここから探します。

Claude アプリからつながらない

「要ログイン」と出ている Claude のログインが切れています。画面共有で入り、ターミナルで claude auth login を実行します。手順は普段の使い方にあります。
「再接続待ち」「停止中」が数分続く 自分の環境 › 「操作」タブ › 「Remote Control を立て直す」を押します。1 分ほどで直ります。切れた会話は「前のセッションを戻す」で戻せます（約 4 時間以内）。
立て直しても直らない 「操作」タブ › 「VM を再起動」を押します。自分の Mac を再起動するので数分かかります。そのあと一覧を確かめます。
Claude アプリに自分の環境が出ない アプリ側のアカウントが、自分の Mac でログインしたアカウント（B / C）と同じかを確かめてください。別のアカウントだと表示されません。

画面共有・SSH・ファイルアプリで入れない

ブラウザで開いたら Cloudflare のログイン画面に戻った ログインの期限（24 時間）が切れています。Google でログインし直します。
「アプリで入る」・ファイルアプリがつながらない Cloudflare One（WARP）がオン（接続済み）かを確かめてください。オフだと 192.168.64.〜 には届きません。ファイルアプリ（smb://192.168.64.〜）も同じで、WARP がオフだとエラーも出ずにしばらく待って失敗します。WARP の準備を見てください。
スマホで、Wi‑Fi のときだけつながらない（タイムアウトする） iPhone の 設定 › プライバシーとセキュリティ › ローカルネットワーク で、SSH アプリと画面共有アプリ（ファイルアプリで止まるときは、一覧に「ファイル」があればそれも）をオンにします。モバイル回線に切り替えるとつながるなら、ほぼこれです。
ファイルアプリで「ユーザ名またはパスワードが正しくありません」 接続方法を「登録ユーザ」にし、名前は自分のユーザー名、パスワードは Mac のログインパスワードです（画面共有の 8 文字ではありません）。「ゲスト」では入れません。
マウスの矢印が見えない ブラウザ版の画面共有ではよく起きます。クリックは効きます。見えにくいときは Mac の画面共有アプリから入ります。
一覧で「応答なし」になっている 接続ではなく Mac 側の問題です。Taro に連絡してください。

パスワードが通らない

画面共有の「Password」欄 ダッシュボードの「パスワードを表示」で出る 8 文字（画面共有 / VNC 用）を入れます。Mac のログインパスワードではありません。
ロック画面（名前の下の欄） Mac のログインパスワード（Taro から受け取ったもの）を入れます。日本語入力がオンになっていると通らないので、英数に切り替えてください。
Mac のパスワードを変えた Taro に伝えてください。自動ログインの設定を直さないと、次の再起動でログイン画面のまま止まります。

Taro に連絡するとき

一覧に何と出ているか、どのボタンを押したか、何分前からかを添えてください。「履歴」タブ（誰がいつ何を押したか）は Taro 側でも見えます。
やらないでほしいこと：ログアウト、macOS の再起動・シャットダウン（ダッシュボードの「VM を再起動」は使ってよい）、スリープや自動アップデートの設定変更、Claude Code の自動更新をオンにすること。
